Note on the original notebook

The raw CSV holds {{ meta.n_rows_raw }} rows but only {{ meta.n_rows_clean }} are unique. Duplicates leak between train and test sets and inflate accuracy (the notebook's near-100% Random Forest score is a symptom). This app removes them and evaluates honestly, so numbers look lower but are realistic.

Labels: the app uses the target column {% if meta.invert_target %}inverted (1 = disease present in the clinical sense){% else %}exactly as stored in the CSV (a prediction of 1 means target = 1){% endif %}. See config.py to change this.
