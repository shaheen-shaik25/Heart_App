About CardioCheck

An advanced version of the original Heart Disease notebook, turned into a full web application.

Features

  • Live risk prediction with a probability gauge and Low / Moderate / High bands
  • 7 models: Logistic Regression, SVM, Random Forest, Decision Tree, Gradient Boosting, KNN and a voting ensemble
  • Per-patient explanation of which values raise or lower the risk
  • What-if simulator, model consensus, personalised lifestyle tips
  • Batch CSV scoring, prediction history, CSV export, PDF reports
  • Interactive data insights and model comparison (ROC, confusion matrix)
  • REST API, dark mode, input validation

REST API

POST /api/predict with JSON:

curl -X POST http://127.0.0.1:5000/api/predict \
 -H "Content-Type: application/json" \
 -d '{"age":63,"sex":1,"cp":0,"trestbps":150,"chol":290,
      "fbs":1,"restecg":0,"thalach":110,"exang":1,
      "oldpeak":3.2,"slope":1,"ca":2,"thal":3}'

GET /api/models returns the evaluation metrics.

Pipeline

  1. Remove duplicate rows ({{ meta.n_rows_raw }} → {{ meta.n_rows_clean }})
  2. Scale numeric features, one-hot encode categoricals (inside a Pipeline)
  3. Stratified split + 5-fold CV grid search
  4. Select best model by cross-validated ROC-AUC ({{ meta.best_model }})
  5. Refit on all data and serve
